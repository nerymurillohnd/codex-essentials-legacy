## Why links, not vendored source

At the pinned revision, generated schemas comprise 23 files and about 26 KB; Rust implementation and
tests comprise 37 files and about 537 KB. Copying them into the skill would add a stale second copy
without making them released behavior. The focused references preserve normal operating knowledge;
these commit-pinned links preserve exact provenance for deep inspection without loading the source
on every invocation.

1. Describe published behavior as released.

3. Verify the target local Codex version if the distinction affects implementation.
4. Do not use a `main`-only field unless the user explicitly targets and verifies a build containing
   it.
