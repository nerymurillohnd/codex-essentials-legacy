# Changelog

All notable changes to Repo Hygiene are documented in this file.

This changelog follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and [Semantic Versioning](https://semver.org/spec/v2.0.0/).

## [Unreleased]

### Added

- Packaged routine and explicit deep Git hygiene workflows in one plugin.
- Added an explicit Git debugging skill for `grep`, `blame`, and approval-gated
  `bisect` investigations.

### Changed

- Split routine housekeeping from the comprehensive topology and recovery audit.
- Classified Git operations into routine reversible hygiene and explicit deep
  revision, integration, recovery, topology, object-store, and provenance work.
- Added command-level evidence, authorization, and recovery boundaries based on
  official Git command and revision documentation.
- Made recommendation, user approval, target revalidation, and item-scoped
  execution mandatory before any cleanup, integration, pruning, or mutation.
- Corrected remote refresh, conflict recovery, merge preview, force-with-lease,
  and debugging command guidance to preserve audit safety and exact semantics.
- Required a plain-language, structured audit report that explains scope,
  findings, risks, retained evidence, and approval-ready recommendations.
- Completed package, skill-agent, license, and marketplace documentation for
  installation, capabilities, permissions, approval boundaries, recovery, and
  verification.
